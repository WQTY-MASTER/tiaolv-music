# 桌面歌词长句滚动设计

## 目标

- 桌面歌词的中文翻译字号从主歌词的 `0.52em` 提高到 `0.62em`。
- 短句保持当前左、中、右对齐方式。
- 当前歌词超过可视宽度时，根据演唱进度从句首平滑向左移动到句尾。

## 行为

- 仅当前行滚动，下一行和离场行保持静止。
- 逐字歌词使用字符填充进度；整行歌词使用当前句开始时间到下一句开始时间的比例。
- 前 8% 保持句首，8% 至 92% 完成横向移动，最后 8% 保持句尾。
- 暂停时冻结位置，拖动进度后立即定位，切换歌词时复位。
- 关闭动画时在句中切换到末尾位置，不持续产生动画。
- 原文、音标和翻译分别判断宽度，只有实际溢出的文本发生位移。

## 实现

- 新增纯函数服务，负责归一化播放进度和滚动进度，便于聚焦单元测试。
- 桌面歌词文本外增加裁剪视口，使用容器查询单位计算内容宽度与可视宽度的差，无需逐帧读取 DOM。
- 播放时只更新 CSS 自定义属性，复用现有 `requestAnimationFrame` 歌词时钟。
- 完整歌曲与歌词状态不再随播放时间逐帧通过 IPC 重发；连续时间只走节流后的时间通道。
- 同一首歌曲的状态刷新不得让渲染时间回退。切歌和用户主动拖动仍可立即回退。

## 验证

- 单元测试覆盖起点、滚动区间、终点、非法时长和关闭动画。
- 单元测试覆盖同曲状态刷新与切歌的时间复位判定。
- 组件契约覆盖当前行进度、独立裁剪视口、超宽文本位移和翻译字号。
- 运行桌面歌词聚焦测试和 Electron 生产构建。
