# 调律音乐 v0.1.4

- 新增本地滚动错误日志，可在「设置 → 关于 → 导出诊断包」手动导出 ZIP。
- 诊断包记录前端、本机服务和更新错误，附主题、窗口及缩放信息，便于反馈排查。
- 修正首次引导选中按钮文字对比度，并改善深色「关于」页的文字可读性。
- 更新服务器分发配置示例，兼容新旧安装包文件名。

诊断日志在本机保存，写入和导出时脱敏，不自动上传，不包含账号配置、数据库或音乐库。
显示问题仍建议附截图与复现步骤；分享前检查诊断文本及截图中的私人信息。

Windows x64 安装包：`Tiaolv-Setup-0.1.4.exe`，自带 Java、本机后端和音乐 API 依赖。
已安装旧版可检查更新，或完全退出后覆盖安装；保留原有音乐库和设置。
在线更新仍由用户主动下载、校验后手动重启安装，不会自动打断播放。

GitHub 与服务器使用同一份安装包、blockmap 和更新清单；服务器需维护者上传后生效。
当前安装包未配置发布者代码签名，请确认来源为官网或本项目 GitHub Release。
