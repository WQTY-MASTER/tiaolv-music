# 流媒体 Daily Mix 主页设计

## 目标

将已登录后的流媒体主页改为“每日推荐横幅 + 私人漫游 + 私人雷达”结构，同时保留网易云音乐与 QQ 音乐音源切换。未登录引导和账号登录流程保持不变。

## 数据与交互

- 每日推荐使用当前平台的账号推荐歌曲接口。
- 横幅右侧最多展示三张推荐歌曲封面；不足时使用项目现有配色生成占位封面。
- “播放全部”从第一首开始播放，并将全部每日推荐写入当前播放队列。
- “查看全部”打开一个临时的每日推荐歌单详情，不额外请求接口。
- 顶部搜索框复用全局流媒体搜索逻辑。
- 切换网易云 / QQ 后，日期结构不变，平台文案、歌曲、封面和目标歌单同步替换，并以 320ms 淡入位移动画刷新。

## 私人漫游

### 产品定位

私人漫游是持续生成的智能播放流，面向“边听边探索新歌”的场景，不等同于固定歌单或每日推荐。推荐依据包括听歌历史、收藏歌曲和偏好曲风，播放过程中持续加载后续歌曲。

### 推荐模式与场景

- 熟悉模式：优先推荐用户经常收听的风格。
- 探索模式：提高陌生歌曲和新音乐的比例。
- 拼图模式：混合多个偏好维度，形成更发散的推荐序列。
- 场景可切换为运动、学习、伤感、咖啡厅等；切换后刷新后续推荐流，不打断当前歌曲。

### 页面与播放行为

- 主页卡片左侧使用圆角方形罗盘图标，中间显示“私人漫游”和“当前平台・为你持续推荐”，右侧使用深色圆形箭头按钮。
- 点击卡片进入独立的私人漫游播放页，并从当前推荐流第一首开始播放。
- 播放接近队列末尾时自动请求并追加歌曲；新结果应去重，不覆盖已经播放的队列。
- 私人漫游页面支持切换推荐模式和场景，并展示当前播放内容及后续队列。

## 私人雷达

### 产品定位

私人雷达是每日更新的固定歌单，重点推荐用户尚未听过、但符合其口味的冷门或陌生歌曲。推荐逻辑以相似听众的收藏和喜欢行为为参考，核心目标是发现新音乐。

### 页面与播放行为

- 主页卡片左侧展示多张错落堆叠的专辑封面，中间显示“私人雷达”和“当前平台・发现更多好音乐”，右侧使用浅色圆形箭头按钮。
- 点击卡片进入私人雷达歌单详情页；详情页复用每日推荐的歌单详情组件，包括播放全部、随机播放、歌单内搜索、排序、定位当前播放歌曲和刷新功能。
- 私人雷达是一份稳定的静态列表，仅在平台每日数据更新或用户主动刷新时替换内容，不按播放进度持续追加歌曲。

## 三类推荐的边界

- 每日推荐：熟悉歌曲与少量新歌混合，固定 30 首，每日 06:00 刷新，适合日常循环播放。
- 私人雷达：以陌生新歌为主，每日生成固定歌单，适合集中发现新音乐。
- 私人漫游：无限流式播放，随播放进度持续加载，并允许切换推荐模式与场景。

## 音源联动

- 切换网易云音乐 / QQ 音乐后，两个卡片的数据、平台文案、封面与目标页面必须同步切换，两个平台状态互不混用。
- 当前平台只有在返回对应推荐能力和数据时才显示相关卡片；例如 QQ 音乐没有私人雷达数据时隐藏私人雷达卡片，不使用每日推荐或普通用户歌单代替。
- 卡片隐藏后，剩余卡片应自然占据可用布局，不保留空白占位。

## 布局

- 页头左侧为“主页”和问候语，右侧为搜索框与云朵音源按钮。
- 主页头部和推荐内容整体下移，为左上角窗口工具留出稳定间距；侧边栏展开与收起时保持相同纵向位置。
- Daily Mix 横幅左侧依次为日期、刷新时间、标题、英文副标题、说明与双按钮；右侧是三张错落封面。
- 下方两张等宽横向卡片分别为私人漫游与私人雷达。
- 980px 以下改为单列，700px 以下缩小横幅字号和封面组，避免横向溢出。

## 边界状态

- 加载中与请求失败沿用现有主页状态提示。
- 每日推荐为空时禁用播放全部，并显示平台暂未返回推荐内容。
- 私人漫游或私人雷达没有对应平台数据时隐藏相应卡片，不回退到每日推荐或普通歌单。
- 系统启用减少动态效果时关闭主页切换动画。
