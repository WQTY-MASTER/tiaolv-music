# 调律音乐开发进度总结

日期：2026 年 9 月 9 日

## 今日完成

本地音乐播放界面继续完善：

- 歌曲详情页支持原歌词与翻译双语显示。
- 原歌词按字符拆分渲染。
- 当前正在唱的歌词按播放时间逐字变蓝。
- 已经唱完的歌词在切换到下一句后恢复普通颜色。
- 翻译显示在原歌词下方，始终不参与高亮。
- 歌词区域支持鼠标滚动；手动滚动后暂时停止自动跟随，约 3 秒后恢复。
- 播放模式菜单支持：
  - 随机播放
  - 顺序播放
  - 单曲循环
  - 列表循环
- 接入本地图标：
  - 返回
  - 播放模式
  - 上一首
  - 下一首
  - 音量
- 播放控制按钮保留鼠标悬停变蓝效果。

## 当前运行方式

后端：

1. 在 IDEA 中启动 Java Spring Boot 后端。
2. 后端地址：`http://127.0.0.1:17890`

前端：

在项目根目录运行：

```powershell
nvm use 24
npm run web:dev
```

浏览器打开：

```text
http://127.0.0.1:5173
```

如果提示 5173 端口已被占用，说明已有前端进程在运行，直接刷新上面的地址即可，不要重复启动多个前端服务。
