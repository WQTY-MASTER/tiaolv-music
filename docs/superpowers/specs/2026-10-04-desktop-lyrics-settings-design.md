# 桌面歌词设置面板设计

## 目标

在“设置 > 桌面歌词”提供完整、实时生效的桌面歌词配置，并让设置页、悬浮窗工具栏、托盘菜单、全局快捷键和原生窗口始终共享同一份持久化状态。

## 方案选择

采用现有 `DesktopLyricsPreferences` 作为唯一配置模型，由 Electron 主进程读取、校验和保存 `desktop-lyrics.json`。主播放器设置页和桌面歌词窗口都通过 preload IPC 读取及修改这份配置，主进程再广播最新快照。避免在设置页增加独立 `localStorage`，防止锁定、翻译、字号等状态分叉。

## 配置模型

- 窗口：`enabled`、`alwaysOnTop`、`locked`、持久化 `bounds`。
- 歌词内容：`translationEnabled`、`phoneticEnabled`。音标只显示 Provider 实际返回的罗马音，缺失时不占行。
- 字体：`fontFamily`、`fontSize`、`fontWeight`、`strokeEnabled`。
- 排版：`lineMode`（单行/双行）、`orientation`（当前仅横排）、`textAlign`。
- 配色：保留封面强调色、落日晖、Twilight、暖白和自定义；每套主题解析为已播放与未播放两个颜色，自定义模式分别保存两个色值。
- 高级外观：`panelOpacity`、`cornerRadius`、`shadowEnabled`、`animationEnabled`。

所有字段经过共享归一化函数校验，旧版配置缺少的新字段自动回退默认值。

## IPC 与窗口行为

- `getDesktopLyricsSnapshot` 同时允许主播放器和桌面歌词窗口调用，返回 `visible`、`bounds`、`preferences` 和播放状态。
- `updateDesktopLyricsPreferences` 同时允许两个窗口调用。主进程应用置顶、锁定穿透和启用状态，并向两个窗口广播。
- 新增尺寸更新 IPC。设置页拖动宽高滑块时，主进程约束尺寸并调用 `setBounds`，窗口 resize 后广播真实 bounds。
- 关闭工具栏 X 或关闭总开关都写入 `enabled: false`；再次开启沿用原位置、尺寸和样式。
- `alwaysOnTop` 只调用桌面歌词窗口的 `setAlwaysOnTop`。
- `locked` 延续现有 `Ctrl+Alt+L`、托盘解锁和顶部窄热区兜底。

## 设置界面

页面采用一张主设置面板，不嵌套装饰卡片：

1. 顶部开关组：启用、置顶、翻译、音标。
2. 显示位置：当前固定为“桌面悬浮”。
3. 字体与排版：使用选择框和分段控件；字体提供 Windows 常用字体列表，不新增原生字体枚举依赖。
4. 配色：主题选择、已播放与未播放颜色输入。
5. 实时预览：使用当前完整配置渲染两行示例歌词。
6. 窗口：宽高滑块与锁定穿透开关。
7. 高级设置：原生折叠面板，包含透明度、圆角、阴影和动画。

总开关关闭后，其余控件置灰但保留值。设置页本地先更新预览，再发送 IPC，因此视觉反馈即时；主进程返回归一化结果后校准本地状态。

## 悬浮窗渲染

- 字体、字重、描边、对齐、圆角、面板透明度、阴影和动画由 CSS 变量及状态类驱动。
- 单行模式只展示当前行；双行模式展示当前行和下一行，保持 QQ QRC 逐字高亮及网易云整行高亮规则。
- 已播放颜色用于当前逐字/整行高亮，未播放颜色用于待唱字符和下一行。
- 翻译与音标作为当前行附属文本，只有开关开启且数据存在时渲染。

## 验证

- 共享状态单元测试覆盖旧配置迁移、边界约束、主题双色解析。
- 原生 IPC 契约覆盖主窗口权限、置顶、尺寸与广播。
- 设置页契约覆盖全部控件、预览、禁用和双向同步。
- 桌面歌词窗口契约覆盖字体、排版、双色、外观和音标渲染。
- 最后运行完整 Electron 测试、构建和开发模式检查。
