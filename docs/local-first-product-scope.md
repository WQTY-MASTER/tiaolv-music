# 当前产品定位

日期：2026-10-10。按用户最新决定，取消独立应用账号和邀请码准入。

## 使用流程

- 调律音乐是以本地音乐为主体的桌面播放器，不要求注册调律账号。
- 首次启动直接显示现有八页引导，允许跳过；不增加激活或邀请码页面。
- 完成或跳过引导后沿用现有完成标记。设置中仍可重新打开引导。
- QQ 音乐和网易云音乐登录是可选的平台功能，不是使用播放器的前置条件。
- 本地扫描、播放、歌单、历史和设置继续由客户端及其本机服务管理。

## 保留的安全边界

平台凭据留在本机，由现有凭据存储负责；不上传到共享服务器，也不复制进安装包。
保留本机接口令牌、loopback 绑定、可信窗口校验及开发代理保护。
本机接口令牌用于保护用户数据，不是邀请码或调律用户账号。

## 本轮清理

删除未接入客户端的独立身份服务源码、测试、构建产物及专属文档。
不删除仓库之外的数据目录，不清除任何现有平台登录、数据库或音乐文件。
本地与在线路由的逻辑分类继续保留；二者当前都使用本机后端。

## 服务器边界

当前安装包仍包含本机 Java 后端和两个音乐 API，不是轻量云客户端。
之前的共享服务器账号、注册和平台绑定计划已取消，不再作为发布前置任务。
如果以后需要服务器提供公共检索或接口转发，应另行设计不共享平台登录状态的方案，
并验收 HTTPS、限流、凭据不留存及请求隔离；不能直接公开现有本机服务端口。
