# 聚合歌单领域规则

## 核心定义

聚合歌单是播放器本地维护的跨平台虚拟歌单。它可以同时包含本地硬盘音乐、网易云在线歌曲和 QQ 音乐在线歌曲，但不会创建、修改或同步任何平台的云端歌单。

## 音源类型

- `local`：本地硬盘文件，不依赖账号登录。
- `netease`：网易云在线音源，播放依赖网易云登录状态。
- `qq`：QQ 音乐在线音源，播放依赖 QQ 音乐登录状态。

网易云与 QQ 音乐账号状态彼此独立，允许同时登录。退出账号不会删除已保存的音源记录，只会令该平台音源暂时不可播放。

## 合并规则

- 使用规范化后的“歌名 + 歌手”作为歌曲身份。
- 身份相同的新歌曲不会新增歌曲行，只会把新平台音源追加到已有行。
- 同一平台、同一曲目 ID 不重复添加。
- 歌名或歌手不匹配时新增独立歌曲行。

## 封面规则

- 歌单存在自定义封面时始终优先使用自定义封面。
- 未设置自定义封面时，使用歌单第一首歌曲的第一个可用封面。
- 歌曲行使用该合并歌曲的第一个可用音源封面。
- 封面不可用时显示稳定的文字占位，不显示破图。

## 音源选择

- 只有一个音源时仅显示来源文字，不显示下拉框。
- 有两个及以上音源时显示下拉框，列出本地、网易云、QQ 音乐等全部音源。
- 播放歌曲、播放全部和随机播放都使用每行当前选中的音源。
- 在线音源未登录、下架或版权失效时，只影响该音源，其他音源仍可切换和播放。

## 删除规则

- 移除当前音源只删除选中的来源；还有其他来源时歌曲行继续保留。
- 删除整行会一次移除该歌曲绑定的全部音源。
- 最后一个音源被移除后，该歌曲行随之消失。

## 持久化边界

聚合歌单、歌曲分组、自定义封面和全部音源记录只保存在播放器本地存储中，不向网易云或 QQ 音乐服务器写入数据。
