# 本地歌曲歌词优先级与缓存设计

## 目标

本地歌曲开始播放时立即使用音频文件内嵌歌词或同目录歌词文件，避免等待联网匹配。联网结果持久缓存，后续播放不再重复搜索，直到用户主动重新匹配或清除缓存。

## 加载顺序

1. 立即展示本地音频标签中的歌词；没有内嵌歌词时读取同目录歌词文件。
2. 若歌词缓存已有结果，直接读取缓存，不发起平台搜索。
3. 本地已有普通歌词时，后台仅尝试用 QQ 音乐逐字歌词升级；失败后继续使用本地歌词，不回退网易云。
4. 本地没有歌词时，依次搜索 QQ 音乐、网易云音乐，使用第一个有效结果。
5. QQ 音乐逐字歌词优先于普通逐行歌词。

## 缓存

- 成功匹配的完整歌词数据写入持久歌词缓存，包括原文、翻译、音译、格式和制作信息。
- 未找到歌词也写入缓存标记，防止每次播放都重复联网。
- 自动匹配首先读取缓存；缓存命中时不访问 QQ 音乐或网易云音乐。
- 设置页清除缓存会同时删除成功结果和未找到标记。
- 用户主动点击“重新匹配歌词”时绕过缓存，重新联网并覆盖原缓存。

## 界面行为

- 有本地歌词时始终立即显示，不再用“正在准备歌词”遮住内容。
- 后台找到 QQ 逐字歌词后无缝替换当前歌词，并保留当前播放时间和高亮位置。
- 没有任何本地歌词且正在首次联网匹配时，继续显示加载状态。
- 缓存命中时直接展示结果，不出现重复匹配提示或明显闪烁。

## 失败处理

- QQ 音乐失败且存在本地歌词：保留本地歌词。
- QQ 音乐失败且不存在本地歌词：继续尝试网易云音乐。
- 两个平台均失败：记录未找到标记，并显示暂无歌词。
- 缓存损坏时忽略该条目并重新匹配，不影响音频播放。

## 验证

- 本地歌词会在联网请求完成前显示。
- 第二次播放同一歌曲不会再次调用平台搜索。
- 未匹配到歌词的歌曲第二次播放也不会重复搜索。
- 手动重新匹配会绕过缓存。
- 清除缓存后再次播放会重新执行 QQ 音乐到网易云音乐的匹配顺序。
