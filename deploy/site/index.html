04 / 安装与更新

几步之后，开始聆听。

安装一次，之后在软件内检查更新。

  1. 01

    下载安装包

    从上方官网下载；连接不畅时，使用 GitHub 备用入口。

  2. 02

    按向导完成安装

    双击下载的 .exe 文件，选择安装目录并完成安装。

  3. 03

    打开调律，导入音乐

    完成或跳过首次引导，导入本地收藏；需要在线曲库时再登录平台账号。

从旧版升级：先完全退出播放器（包括托盘），再覆盖安装。默认保留音乐库和设置，重要数据可先备份，无需删除音乐库或先卸载。

软件内在线更新

听完这一首，
再决定什么时候升级。

入口：设置 → 关于

  1. 检查更新查看是否有新版本
  2. 下载更新主动下载，查看进度
  3. 重启安装下载和校验完成后，由你确认

不会自动下载，也不会在普通退出时自动安装。只有点击「重启安装」，播放器才会退出进行升级。下载失败时，可通过 GitHub 手动下载并覆盖安装。

尚未接入在线更新的旧版（如 0.1.0），需先手动覆盖安装一次。

05 / 常见问题

开始之前，
你可能想知道。

关于调律的几个小问题。

支持哪些设备？需要安装其他软件吗？+

当前版本为 0.1.4，仅支持 Windows x64 桌面设备。安装包包含所需运行环境，普通用户无需另装 Java、Node.js 或数据库。此网站提供介绍和下载，不能在网页上播放音乐。

需要注册账号才能使用吗？+

无需注册调律账号，也无需邀请码或激活。首次打开可以完成或跳过使用引导；QQ 音乐和网易云音乐仅在使用对应平台功能时按需登录。

没有网络，也可以听歌吗？+

可以播放电脑上已保存的本地音乐。在线搜索、在线曲库和联网歌词匹配等功能需要网络；本地音乐播放不依赖调律的下载服务器在线。

在线歌曲都能直接播放吗？+

歌曲是否可用取决于对应平台的账号权限、版权、地区及服务状态。调律不会改变平台原有的访问权限，也不绕过会员或版权限制。

音乐库和平台登录信息存在哪里？+

音乐库、歌单、历史、设置和平台登录凭据由客户端及本机服务管理，不上传到调律的分发服务器。使用在线功能时，会与对应平台通信。

更新会突然打断正在播放的音乐吗？+

不会。检查更新、下载更新和重启安装分别由你主动操作；普通退出不会自动安装。只有选择「重启安装」时才会退出播放器。

覆盖安装会清空收藏吗？安装来源怎么确认？+

覆盖安装默认保留本机音乐库和设置，重要数据建议先备份。当前安装包暂未配置发布者代码签名，请确认安装包来自官网或本页链接的 GitHub Release。软件内更新会执行 SHA512 校验；校验不能替代发布者代码签名。
