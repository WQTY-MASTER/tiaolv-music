# 快捷键设置

入口：设置 > 快捷键。配置保存在 Electron 用户数据目录的 `shortcuts.json`，与资源缓存、歌单、聆听记录独立。使用临时文件加原子替换保存；保存失败保留原配置并提示错误。

| 操作 | 默认组合键 |
| --- | --- |
| 播放 / 暂停 | Ctrl + Alt + Space |
| 上一曲 / 下一曲 | Ctrl + Alt + 左 / 右 |
| 音量增加 / 减小 | Ctrl + Alt + 上 / 下 |
| 切换循环模式 | Ctrl + Alt + R |
| 收藏当前歌曲 | Ctrl + Alt + S |
| 显示 / 隐藏主播放器 | Ctrl + Alt + M |
| 显示 / 隐藏桌面歌词 | Ctrl + Alt + D |
| 解锁桌面歌词 | Ctrl + Alt + L |
| 歌词翻译开关 | Ctrl + Alt + T |
| 桌面歌词置顶开关 | Ctrl + Alt + P |

- 点击组合键进入录制，松开主键时提交，Esc、失去焦点、离开页面或 30 秒超时取消。录制期间暂停全局注册和应用内动作，避免误触。
- 组合键需包含 Ctrl / Alt / Win，或使用 F1–F24；只按修饰键不提交。
- 总开关默认开启。关闭后注销全部全局热键，保留应用窗口内的组合键响应。
- 内部重复组合键拒绝保存；修改某条热键遇到系统注册失败时保留原键位，并显示红色错误。
- 启动、开启总开关或恢复默认时，逐条注册并标记失败项，不妨碍其他可用快捷键。Electron 无法可靠判断具体占用软件，提示为“已占用或不受系统支持”。关闭全局开关时仅校验内部重复，系统冲突在重新开启时检查。
- 恢复默认会恢复全部键位并开启全局快捷键。配置修改即时生效，无保存按钮。
- 音量每次增减 5%，约束在 0–100%；循环模式沿用播放器已有的顺序、列表循环、单曲循环、随机模式；收藏沿用当前歌曲的收藏切换逻辑。
- 主窗口隐藏使用最小化，避免关闭全局热键且托盘关闭时无法找回窗口。再次触发则恢复显示。
- 桌面歌词锁定不依赖某个固定组合键。设置页、托盘和顶部解锁热区保留兜底入口，设置页显示当前有效解锁键位。
- 主进程统一分发，已注册的全局热键不再由窗口内重复执行；窗口内忽略长按重复事件。

验证：`node --test tests/shortcuts.test.cjs`（在 electron 目录运行）。
