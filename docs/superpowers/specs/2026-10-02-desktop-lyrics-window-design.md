# 桌面歌词悬浮窗设计

## 目标

将主播放器现有的桌面歌词预览层替换为真正独立的 Electron 悬浮窗。点击底部播放栏“词”按钮或托盘“桌面歌词”后打开/关闭悬浮窗；悬浮窗始终置顶，主播放器最小化后仍可显示歌词。

## 窗口架构

- 主进程创建独立无边框、透明、可缩放、跳过任务栏的 `BrowserWindow`。
- 开发环境加载当前 Vite 地址并附加 `window=desktop-lyrics` 查询参数；生产环境加载同一 `index.html`。
- 渲染入口根据查询参数挂载 `DesktopLyricsWindow.vue` 或主应用 `App.vue`，避免第二套工程入口。
- 桌面歌词窗不创建音频元素。主播放器是唯一播放状态源，通过 IPC 推送曲目信息、原始歌词、翻译、格式、播放状态、循环模式和当前时间。

## 歌词展示

- 悬浮窗复用现有 QRC/YRC/LRC 解析器和歌词同步函数。
- 渲染完整歌词列表，当前行变化时平滑滚动到窗口中心。
- 逐字歌词根据当前播放时间计算每个字符的填充比例；已经唱过的字符维持完成色，不发生回退或变淡。
- 翻译开关仅控制译文显示，不重新解析或销毁歌词 DOM。

## 工具栏与交互

- 工具栏顺序固定为：上一曲、播放/暂停、下一曲、A−、A+、循环、翻译、锁定、关闭。
- 工具栏初始隐藏。未锁定时，鼠标进入窗口淡入、移出淡出；按钮使用 `title` 和 `aria-label` 提示。
- 歌词区域是窗口拖动区域，按钮声明为非拖动区域；窗口边缘保留原生缩放能力。
- 关闭按钮销毁悬浮窗，再次点击“词”会重新创建。

## 锁定与快捷键

- 锁定后主进程调用 `setIgnoreMouseEvents(true, { forward: true })`，窗口鼠标穿透且工具栏不再出现。
- 锁定成功时注册全局快捷键 `Ctrl+Alt+L`；该快捷键只执行解锁，不用于锁定。
- 如果全局快捷键注册失败，则拒绝进入锁定状态，防止用户无法操作窗口。
- 锁定后托盘不提供解锁操作，只显示快捷键提示。

## 持久化

主进程在 Electron `userData` 目录保存 JSON 配置：窗口位置、窗口大小、锁定状态、翻译开关和字号。窗口移动或缩放时节流写入；启动时验证字段范围并把窗口约束在当前显示器可用区域。字号范围为 20 到 64 像素。

## IPC 与托盘

- 主播放器推送完整歌词状态和节流后的播放时间。
- 桌面歌词操作由主进程转发到主窗口，再复用上一曲、播放暂停、下一曲和循环模式函数。
- 主进程向主窗口广播桌面歌词可见状态，托盘复选状态与底部“词”按钮保持一致。
- “设置 → 快捷键”展示“解锁桌面歌词：Ctrl+Alt+L”。

## 验证

- 单元测试覆盖配置归一化、字号边界和逐字填充稳定性。
- 契约测试覆盖独立窗口参数、置顶、持久化、IPC、工具栏顺序、悬浮显隐、锁定穿透、全局快捷键和主播放器按钮联动。
- 运行完整 Electron 测试、生产构建与 Git 空白检查。
