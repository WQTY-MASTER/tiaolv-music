# 调律音乐

调律音乐是一款面向 Windows 桌面的本地与流媒体音乐播放器，使用 Electron、Vue 3 与 Java 21 构建。

[官网与下载](https://wqty.online/#download) · [GitHub Releases](https://github.com/WQTY-MASTER/tiaolv-music/releases/latest) · [更新日志](更新日志.md)

打开即可使用，无需注册调律账号、邀请码或激活。首次启动直接进入八页引导，
可以跳过；QQ 音乐和网易云音乐仅在使用对应平台功能时按需登录。
本地音乐、歌单、历史、设置和平台登录凭据由客户端及其本机服务管理，
不上传到调律的分发服务器。当前产品定位见 [本地优先说明](docs/本地优先产品说明.md)。

## 下载与安装

当前发布版本为 **0.1.7**，支持 **Windows x64**。

1. 从 [官网下载页](https://wqty.online/#download) 或 [GitHub Releases](https://github.com/WQTY-MASTER/tiaolv-music/releases/latest) 下载安装包。
2. 双击 `Tiaolv-Setup-0.1.7.exe`，按安装向导选择目录并完成安装。
3. 打开调律音乐，导入本地音乐；使用在线曲库时，再登录自己的 QQ 音乐或网易云音乐账号。

这是安装版，不是免安装版。安装包已包含所需 Java 运行时、本机后端和
音乐 API 依赖，普通用户无需安装 Node.js、Java、Maven、数据库或开发工具。
开发环境要求仅适用于下方的源码开发流程。

已有旧版请先完全退出软件，包括托盘，再覆盖安装。默认保留应用数据，
无需卸载或删除音乐库；重要数据可先按 [备份与恢复说明](docs/发布检查与恢复说明.md#offline-backup) 备份。

## 当前能力

- 本地音乐库扫描、增量更新、文件名元信息补全与重复歌曲标记
- 网易云音乐与 QQ 音乐账号、曲库、搜索、歌单和播放
- 网易云 YRC、QQ 音乐 QRC 逐字歌词及普通 LRC 降级
- 本地歌词文件、联网歌词匹配与歌词缓存
- 在线歌单账号切换、歌单歌曲增删和失败原因提示
- 本地、流媒体与聚合歌单的批量整理、进度显示及失败项重试
- 歌单原图封面管理；只清理不再使用的封面文件
- 播放队列、迷你播放器、桌面歌词、任务栏缩略图按钮与系统托盘控制
- 双语歌词布局、主题适配和与界面风格统一的窗口控制按钮
- QQ 音乐真实播放累计满 30 秒后上报云端最近播放，每次播放会话最多一次，不补报历史记录
- 在线检查更新、下载进度、安装包 SHA512 校验与手动重启安装
- 本地滚动错误日志与手动导出脱敏诊断 ZIP，不自动上传

在线曲库、收藏、歌词和播放能力受平台接口、账号权限及网络状态影响，
不绕过会员、版权或地区限制。

## 在线更新

在「设置 → 关于 → 检查更新」查看版本；发现新版后点击「下载更新」，
下载和校验完成后再点击「重启安装」。不会自动下载，也不会在普通退出时
自动安装；只有主动选择重启安装才会退出播放器进行升级。

- 优先从 `https://wqty.online/updates/windows/` 检查版本。
- 服务器检查或更新清单校验失败时，回退一次到 GitHub Releases。
- 下载失败时，可通过界面提供的链接打开 GitHub Release 手动下载并覆盖安装。
- 支持增量下载；增量不可用时回退到完整安装包。下载后由主进程进行 SHA512 校验。

未接入更新功能的旧版（如 0.1.0）需要先手动覆盖安装一次。
哈希校验不能替代发布者代码签名，也不能防御安装包与清单同时被篡改。
发布者说明见 [GitHub 更新流程](docs/GitHub更新说明.md) 和 [服务器分发说明](docs/服务器部署说明.md)。
官网的静态源码与公开截图保存在 [deploy/site](deploy/site/README.md)，与当前发布版本同步。

## 数据与服务器

官网服务器只分发介绍页、安装包和更新文件，不托管用户的音乐库、平台登录
或播放器后端。搜索、歌词、收藏与在线播放由用户电脑上的本机服务请求对应
平台，不通过调律的下载服务器；本地音乐播放不依赖该服务器在线。

不同电脑或 Windows 用户可独立安装、使用自己的平台账号。相同 Windows
用户下的多次启动共用该用户的数据，不是相互隔离的调律账号。
服务器多人下载可能影响官网和更新速度，但音乐 API 不共用这台分发服务器的带宽。
本机网络拥堵及平台自身限制仍可能影响在线功能。

## 开发环境

- Node.js 24（验收使用版本；启动工具需要原生 TypeScript 支持）
- Java 21
- Maven 3.9 或更高版本
- 网易云音乐 API 与 QQ 音乐 API 源码及锁文件；服务仅绑定本机

安装依赖：

```powershell
pnpm install
```

启动完整开发环境：

```powershell
npm run runtime:stage -- --online
npm run dev
```

暂存工具构建后端、生产 API 依赖和 Java 21 运行时，不复制账号配置。
首次需要联网安装依赖；离线缓存完整时可省略 `--online`。
开发服务与安装包使用相同的受保护启动入口，占用端口不会被强制清理。
仅启动三个服务可运行 `npm run services`；修改后端/API 后需要重新暂存。

仅启动前端网页预览：

```powershell
npm run web:dev
```

## Windows 安装包

```powershell
npm run release:win
```

产物位于 `electron/release/`。安装包包含 Java、后端和两个 API 的生产依赖，
用户机器不需要安装 Node、Java 或 Maven。当前只支持 Windows x64。
从 0.1.3 起，安装包统一命名为 `Tiaolv-Setup-<版本号>.exe`。
软件名称、应用身份和数据目录不变；旧版本下载链接继续保留。
此命令不代替干净 Windows 安装、真实账号播放、代码签名及许可证审核。

启动时自动管理 `17890`、`3000`、`3300` 三个服务，退出仅清理自身启动的进程。
私有接口需要本地访问令牌，令牌默认位于
`%USERPROFILE%/.tiaolv-music/local-access.token`，不会写入前端代码或 URL。
Electron 主进程和开发网页同源代理注入令牌；不再直接从普通网页调用后端。
不要分享该文件，也不要把 API 服务绑定到局域网地址。

## 项目结构

- `electron/`：Electron 主进程、Vue 渲染层与前端契约测试
- `backend/`：Spring Boot 服务、SQLite 数据层与后端测试
- `music-api/api-enhanced/`：项目当前使用的网易云音乐 API
- `music-api/qq-music-api/`：项目定制的 QQ 音乐 API 源码、测试与依赖锁文件
- `scripts/`：开发环境启动脚本
- `docs/`：使用边界、发布与恢复流程、设计说明与实现计划

QQ 音乐 API 定制源码随本仓库提交，克隆后无需另行准备上游仓库。上游版本与本地修改范围见 [源码来源说明](music-api/qq-music-api/TIAOLV_UPSTREAM.md)，保留其 [MIT 许可证](music-api/qq-music-api/LICENSE) 和 [第三方声明](music-api/qq-music-api/THIRD_PARTY_NOTICES.md)。依赖与构建产物不提交，由暂存工具构建。直接运行上游 API 不会自动启用本项目的访问保护，不建议用于日常启动。

## 数据兼容

应用数据默认存放在用户目录下的 `.tiaolv-music`。从旧版升级时，程序会自动迁移原 `.listen-music` 数据目录和浏览器本地设置，不会修改音频文件本身。

Electron 设置位于 `%APPDATA%/调律音乐`。备份或恢复前需完全退出应用和
三个服务，使用 `npm run data:backup -- --archive <新目录>` 与
`npm run data:restore -- --archive <备份目录>`。默认不备份凭据，恢复保留
原数据的回滚副本；详细限制与回滚步骤见发布检查说明。
