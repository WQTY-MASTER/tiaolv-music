# 顶部菜单与侧栏收起设计

## 目标

为调律音乐主页增加固定在左上角的菜单按钮，让用户可以完全收起或重新显示左侧导航栏；设置按钮同时固定在菜单按钮旁边，作为后续设置功能的入口。

## 交互

- 侧栏默认显示，保持现有导航、账号、歌单和模式切换行为。
- 点击菜单按钮后，侧栏完全隐藏，主工作区横向占满窗口。
- 侧栏收起后，菜单按钮仍然显示在顶栏最左侧，点击后恢复侧栏。
- 菜单按钮的 `title` 和 `aria-label` 根据当前状态显示“收起侧栏”或“展开侧栏”。
- 设置按钮暂时只保留入口，不改变当前页面和播放状态。

## 实现边界

- 状态放在 `App.vue`，由根布局 class 控制网格列数。
- `SidebarNav` 在收起状态下不渲染，避免保留空白列。
- 不改变路由历史、播放器、歌词同步、播放队列和模式切换逻辑。
- 不引入新的依赖或图标库，沿用项目现有按钮样式。

## 验收标准

1. 初次打开应用时侧栏可见。
2. 点击菜单按钮后侧栏消失且内容区域填满原侧栏空间。
3. 收起后菜单按钮仍可见，点击后侧栏恢复。
4. 设置按钮位于菜单按钮右侧并保留现有设置入口。
5. 前端契约测试和构建通过。
