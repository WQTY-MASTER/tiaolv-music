# 问题反馈与诊断

0.1.4 起提供「导出诊断包」。0.1.3 及更早的安装版只提供版本信息复制，
需要先升级；旧版发生的错误不会自动补录。

## 遇到问题时

1. 记下发生时间、软件版本，以及从哪个页面进行哪些操作。
2. 问题发生后，打开「设置 → 关于 → 系统信息 → 导出诊断包」。
3. 选择保存位置，将 ZIP 和复现步骤发给维护者；界面问题另附截图。
4. 软件崩溃时可重新打开后导出，最近的日志仍会保留。不要发送整个应用数据目录。

建议反馈格式：

```text
软件版本：
发生时间：
操作步骤：
预期结果：
实际结果／错误提示：
是否每次发生：
附件：诊断 ZIP、必要的截图
```

## 看不清文字等显示问题

即使其他电脑显示正常，也值得反馈。先提供系统截图，不要只拍显示器。
说明受影响的按钮或文字、浅色／深色主题，以及 Windows 缩放比例。
诊断包补充主题色、排版密度、字体选项、窗口尺寸、屏幕缩放和应用缩放。

如果系统截图看起来正常，但本人在屏幕上仍觉得过亮，可另附屏幕照片，
并说明显示器型号、亮度及 HDR／夜间模式状态。这些硬件显示条件不会
自动收集，日志也不能代替视觉反馈。

## 包含什么

- 软件、系统与运行环境版本，本机服务连接情况和最近的服务状态。
- 主进程和渲染页面错误、API 失败的路径／方法／状态码／耗时。
- 更新来源、失败阶段和具体错误，例如服务器安装包返回 HTTP 404。
- 本机后端、QQ 和网易云服务的错误行、调用栈及退出码。
- 上述显示设置，不包含自定义背景图片或其路径。

日志位于 `%APPDATA%/调律音乐/logs/diagnostics`，六类日志各保留最多
三个 1 MiB 文件，正常写入合计最多约 18 MiB，旧记录自动轮换。
日志不可写或错误过于密集时，诊断概要会记录写入失败或丢弃条数。

## 隐私边界

诊断只写入本机，不自动上传，不扫描账号配置、数据库、音乐库或其他文件。
Cookie、登录票据、访问令牌、URL 查询参数、常见账号标识和个人路径在写入时
脱敏，导出时再次脱敏。不会保存正常播放内容、完整请求头、请求体或响应体。

脱敏无法保证识别第三方错误文本中所有未知格式的私人信息。分享前可查看
ZIP 中的 `diagnostics.json` 和日志；截图也应遮挡昵称及其他不愿公开的信息。
诊断包建议私下发送，避免直接上传公开 Issue。仅有日志不保证一定能复现问题。

## 开发验证

```powershell
pnpm --filter tiaolv-music-electron test:diagnostics
node --test electron/tests/service-runtime.test.cjs
pnpm --filter tiaolv-music-electron test:updates
pnpm --filter tiaolv-music-electron typecheck
pnpm --filter tiaolv-music-electron build
node electron/tests/diagnostics.smoke.cjs
```

最后一项需安装 Playwright，也可将其模块路径作为第一个参数传入。
它使用独立测试数据、阻断真实本机后端请求，不登录账号或修改收藏，
验证导出成功／取消／失败重试、IPC 权限及选中文字对比度。
