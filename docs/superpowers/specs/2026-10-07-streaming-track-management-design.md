# 流媒体歌单歌曲管理

用户要求：我喜欢和自建歌单长按歌曲后上下移动，顺序同步 QQ；批量取消喜欢、添加喜欢及从自建歌单删除歌曲。整张“我喜欢”始终不可删除。

沿用详情页，在工具栏增加批量操作入口，开启后序号变复选框；全选只影响当前筛选可见歌曲。喜欢歌单显示取消喜欢，普通自建歌单显示添加喜欢、移出歌单。逐项处理，成功项取消选择，失败项保留并显示数量；写入中禁止重复操作。切换歌单不让旧结果污染新页面。

长按 450ms 激活拖动，提前移动取消长按；放手不会误播放；只有无筛选的默认顺序可调整。保存期间禁止再次排序，只有 QQ 确认后更新顺序。不能以删除再添加代替排序。

后端用 QQ 目录类型识别喜欢与可编辑歌曲列表，不依赖名称；所有写操作服务端重新验证当前账号归属。移出歌曲保留真实歌曲 ID 与类型，拒绝未知条目，不调用删除整张歌单接口。

本地上传和默认列表来自 QQ 预置目录。目前禁止整张删除是本项目的保守保护，尚未验证 QQ 是否允许删除，保留原有保护。

验证：部分失败、筛选全选、长按取消/释放、账号与页面切换、所有权校验、喜欢歌单保护；真实写操作限临时测试歌单，测试后删除。
