# 优先播放本地下载品质设计

## 目标

在播放设置增加“优先播放本地下载品质”开关。开关默认开启；播放 QQ 音乐或网易云音乐曲目时，如果本地音乐库存在可靠匹配的文件，则使用本地音频地址播放，同时继续保留平台歌曲的身份、封面、歌词、收藏和听歌记录语义。

## 匹配规则

- 仅处理来源为 `qq` 或 `netease` 的在线曲目。
- 候选必须来自已扫描的本地音乐库，并具有可播放地址。
- 歌名和歌手经 Unicode 规范化、大小写折叠、空白与常见标点清理后必须完全一致。
- 在线与本地时长都有效时，时长差不得超过 3 秒。
- 多个候选同时通过时，优先无损格式、更高位深、更高采样率，然后选择时长最接近者；最后按稳定 ID 排序，保证结果可预测。
- 不修改本地文件，不把推测结果写回数据库。

## 播放与回退

在线歌曲详情和歌词仍按原平台加载。解析到网络音频地址后，再选择本地候选并临时替换本次播放的音频地址，同时保存网络地址作为回退。若本地地址无法播放，播放器在同一次播放请求中自动切回网络地址；回退只执行一次，避免循环重试。

## 设置界面

开关位于“音乐渐进渐出”之后，使用与其他播放设置一致的透明行背景、分隔线、间距和开关控件。设置保存在 `localStorage`，键名沿用 `tiaolv-music-` 前缀，并兼容旧品牌前缀迁移。

## 验证

- 单元测试覆盖可靠匹配、时长拒绝、在线来源限制和多候选音质排序。
- 契约测试覆盖默认开启、设置持久化、播放入口接入、本地失败回退及 UI 文案。
- 运行 Electron 全量测试、生产构建和 Git 空白检查。
