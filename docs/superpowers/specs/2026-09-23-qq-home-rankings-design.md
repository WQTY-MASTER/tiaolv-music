# QQ 首页双榜单设计

## 目标

在 QQ 音乐登录后的首页中，将「飙升榜」和「热歌榜」放在「QQ 音乐 为你精选」模块下方。网易云首页、QQ 未登录页和本地模式均保持不变。

## 数据与交互

- 使用 QQ 音乐真实排行榜列表确定「飙升榜」和「热歌榜」的榜单 ID，再分别加载榜单歌曲。
- 首页卡片各展示前三首歌曲，包含序号、封面、歌曲名、歌手和播放入口。
- 点击歌曲后以该榜单作为播放队列，并从所选歌曲开始播放。
- 点击卡片底部「查看全部」或卡片入口时，复用现有流媒体歌单详情模板展示完整榜单，不新增重复详情页面。
- 两个榜单独立加载；单个榜单失败只影响自身，并提供重试入口，不阻断每日推荐。

## 界面

- 桌面端使用左右双栏卡片，窄屏切换为单栏。
- 左卡为淡绿色「巅峰 · 飙升榜」，右卡为淡蓝色「巅峰 · 热歌榜」。
- 延续现有首页的紧凑信息密度、轻边框和小圆角，不嵌套额外卡片。
- 模块仅在 `streamingSource === "qq"` 且 QQ 账号已登录时渲染。

## 实现边界

- QQ API 层负责获取排行榜元数据与榜单详情。
- Java Provider 将 QQ 榜单统一映射为现有 `HomepagePlaylist` 和 `Track` 模型。
- Electron 首页复用现有歌单导航、队列播放与详情模板。
- 仅添加聚焦的接口解析与界面契约检查，不扩展网易云逻辑。

## 验证

- 验证两个榜单均返回真实歌曲和封面。
- 验证首页前三首展示、单曲播放和「查看全部」跳转。
- 验证网易云首页无新增榜单模块。
